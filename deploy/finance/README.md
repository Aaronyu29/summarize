## 发布日期标注

后续自动生成的飞书标题与 Lark 消息均显示“视频发布：YYYY-MM-DD HH:MM:SS（北京时间）”。时间复用封存分析中的视频发布日期，不使用扫描或报告生成时间；缺失或无时区的来源时间阻止投递。已完成视频不重新发消息。

## 自动失败告警

分析、转写、飞书上传或核验失败会生成持久化 Lark 告警，包含视频标题、原始发布日期（北京时间）、失败阶段、脱敏原因、后续处理状态、视频链接及告警编号。发布日期尚未取得时明确标为未知，不借用扫描日期。服务被信号终止、超时或资源限制中断时由 ExecStopPost 补发告警。

同一视频、阶段、原因及处理状态确认发送成功后不重复通知。Lark 网络或接口本身失败时保存待发送告警，在下一次扫描及服务退出时重试；网络结果不明可能造成相同编号的重复告警，优先保证故障可见。分析/上传的原有去重保护不变，告警重试不会重跑模型或重建文档。若服务器完全离线，则必须等网络或主机恢复才能发出通知。

2026-10-23 云端 38 项测试通过；已向 Lark 发送一条明确标为“演练、非真实失败”的通知，确认首次 sent=1、重复调用 sent=0，记录为 data/alert-verification.json。告警正文不包含异常原文、密钥或签名下载地址。

## 每期 token 与成本

每次模型响应保存后自动更新该视频的 `cost-summary.json`，全局汇总为 `data/cost-ledger.json`。按实际 API usage 统计输入、缓存命中/未命中、输出及请求数；推理 token 已包含在输出中，不重复计费。初稿、修订、全部审核和失败但有响应的调用均计入；复用缓存不新增计费记录，同一 response ID 只计一次。结果不明的请求和缺失 usage 明确标为不完整，不当作零费用。

价格快照为 2026-10-23 DeepSeek 官方人民币价：空闲每百万输入缓存命中 0.02 元、未命中 1 元、输出 4 元；高峰翻倍。每次调用以 API created 时间转换北京时间判断时段。折算费用不等于账户账单实扣，不含服务器固定成本或单独的部署预检调用。价格未来可能变更；可在 data/cost-pricing.json 设置同结构价格快照及 holidays 日期列表，以匹配新费率和法定节假日，既有报告保留当时快照。
